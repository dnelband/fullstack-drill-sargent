# Practice Fullstack

Reusable interview-style tech challenges live in this repository.

## Layout

- `stacks/`: one isolated project per stack
- `.solutions/`: hidden validated reference solutions

## Current Stacks

- `stacks/vite-express-postgres/`: Vite + Express + Postgres + Tailwind challenge workspace
- `stacks/mern/`: Vite + Express + MongoDB (native driver) + Tailwind challenge workspace

## Workflow

1. Open a stack folder in VS Code.
2. Start the app terminals for the current challenge.
3. Start the challenge tests in watch mode.
4. Solve only inside the exercise paths.

Each challenge ships with seeded data, a README, and task-oriented Vitest coverage.
